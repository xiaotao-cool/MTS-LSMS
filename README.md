多终端网络安全监测与日志管理平台（毕业设计） 2026/03 - 2026/06

技术栈：Spring Boot + MySQL + Spring Data JPA + Java NIO + Spring AOP + RESTful API

项目简介
面向 PC、服务器、移动终端等多终端接入场景，实现日志统一采集、数据预处理、安全规则检测、告警处理及可视化展示，提升多终端
网络安全数据的集中管理与异常行为发现能力。

项目规模
实现日志采集、数据预处理、安全监测、数据存储、终端管理、告警处理、权限管理、规则配置、黑名单管理、操作日志、数据可视
化等核心功能。
支持 HTTP 接口 + 本地文件监听 双轨日志采集，实现多终端日志统一接入。
基于 12 张核心业务数据表完成日志、安全事件、终端、用户权限、告警及系统配置等数据管理。
实现异常登录、高频访问、非法 IP、跨终端威胁、终端离线等 5 类安全规则检测。

个人职责
基于 Spring Boot 搭建系统后端架构，完成核心业务模块及 RESTful API 的设计与开发。
设计日志采集与预处理流程，通过 Java NIO WatchService 实时监听本地日志文件，并对多来源日志进行清洗、时间校正及格式标
准化处理。
设计并实现规则驱动的安全监测模块，对异常登录、高频访问、非法 IP、跨终端威胁及终端离线等行为进行检测并生成安全事件。
基于 RBAC + BCrypt 实现用户认证、角色及权限控制，保证后台接口访问安全。
使用 Spring AOP + 自定义注解 实现操作日志自动记录，将用户、操作类型、操作内容及时间等信息统一持久化，降低业务代码与审
计逻辑的耦合。
使用 MySQL 完成核心业务数据存储与索引设计，并结合缓存思路优化高频数据查询；使用 ECharts 实现日志、安全事件及终端状态
的可视化展示。
